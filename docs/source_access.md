# 직접 수집 소스 접근성 확인표

- 확인일: 2026-11-05 (Day 1)
- 확인 방법: 각 사이트 `robots.txt` 직접 조회, 검색·상세 페이지 구조 시험 요청 1~2회
- 판정 기준: `User-agent: *` 규칙 기준. 자동 수집 불가 시 API 또는 수동 다운로드(사람이 브라우저로 개별 다운로드)로 대체

## 2. 사용자 조치 필요 항목 (API 키 발급)

| 항목 | 발급처 | 용도 | `.env` 키 |
|---|---|---|---|
| 네이버 검색 API | developers.naver.com 애플리케이션 등록 | 블로그 요약문 수집 | `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` |
| 법령 Open API | open.law.go.kr 신청 (OC 값) | 법령 원문 | `LAW_OPEN_API_OC` |
| 열린국회정보 Open API | open.assembly.go.kr 인증키 신청 | 의안 목록 조회 | `ASSEMBLY_API_KEY` |
| OpenAI | 교육 과정 제공 | 임베딩·생성 | `OPENAI_API_KEY` |

- API 발급이 지연되면 법령·의안은 수동 다운로드로 대체 가능. 블로그는 P2이므로 최후순위

## 3. 정책브리핑 사전 시험 결과

- 보도자료 검색 파라미터: `srchWord`, `startDate`, `endDate`, `period=direct`, `pageIndex`
- `지역사랑상품권` 검색 결과 2021-10-16 ~ 2026-11-05 기간 153건
- 검색이 본문·첨부까지 매칭하는 것으로 보여 제목·본문에 키워드가 없는 결과도 포함됨 → 수집 후 관련도 필터 필요
- 상세 페이지 구성: 제목, 등록일, 본문 텍스트, 첨부(PDF·HWP 동시 제공)
- 이용 조건: 본문 텍스트는 공공누리 제1유형(출처표시) 조건으로 이용 가능하다는 안내 문구 존재, 사진·이미지·일러스트는 별도 저작권 → 텍스트만 수집

## 4. 상충 근거 확보 가능성 (종합·판단 문항용)

- 2020년 9월 조세재정연구원 보고서는 지역화폐의 지역경제 활성화 효과가 통계적으로 유의하지 않다고 결론
- 같은 시기 경기연구원·한국지방행정연구원은 긍정적 효과를 추정하여 반박
