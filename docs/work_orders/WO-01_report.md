- 연구·평가 자료의 고유 후보 4건으로 5~10건 목표 미달, 원본 저장 완료 0건

## 6. 제안

- NABO 2025년 평가자료의 운영지침 인용(2025년 6월판)을 기준으로 행정안전부 첨부 원문을 우선 수동 회수할 필요
- NABO 2021~2025 예산안·결산 분석 5건을 연도별로 수동 확보하고, 각 파일에서 지역사랑상품권 관련 쪽만 `include_pages`로 지정할 필요
- 국회 검토보고서는 의안번호 6건을 LIKMS에서 검색해 실제 검토보고서·심사보고서 PDF 여부를 대조할 필요
- NARS는 확인된 2020년 보고서 외에 2022년 이후 관련 이슈·현안 분석 자료를 추가 검색할 필요
- 지역경제 효과의 양·음 효과를 단일 결론으로 요약하지 말고, 순소비 증가·역내 소비 전환·타 업종 대체·재정 이전효과·지역 간 재정 형평성을 구분하는 자료를 추가 확보할 필요
- 2023년 「지역사랑상품권의 효율적 운영을 위한 적정성 분석」(감사연구원 연구자, 학술지 논문)은 국비지원 배분의 편중·운영비·자금관리·부정유통 사후관리 문제를 분석한 비판 관점 자료이나, 지정된 `doc_type`과 수집 범위의 연구보고서가 아니므로 목록화만 제안
- 2025년 「정부의 지역사랑상품권 재정지출이 소상공인 매출에 미치는 영향: 판매액의 매개효과를 중심으로」(학술지 논문)는 재정지출의 판매액 매개 경로를 분석한 최신 자료이나, 연구보고서 형식이 아니므로 목록화만 제안
- 지자체 운영 안내는 할인율·캐시백뿐 아니라 가맹점 매출액 기준, 구매·보유 한도, 사용처, 환전 기준, 예산 소진 시 종료 조건을 확인할 수 있는 상세 운영지침·공고를 우선 회수할 필요
- 전북연구원 자료의 변경금지 조건과 RAG 전처리·청크화 방식의 적합성을 프로젝트 담당자가 별도 검토할 필요
